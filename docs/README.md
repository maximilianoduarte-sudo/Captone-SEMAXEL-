# Documentación SEMAXEL

Evidencias del proyecto de título SEMAXEL (PTY4614 Capstone, Duoc UC),
ordenadas según la estructura pedida por la asignatura. El código de la
aplicación está en la raíz del repositorio.

```text
docs/
├── Fase 1/
│   ├── Evidencias Individuales/   Apellido_Nombre_1.1, 1.2 y 1.3 de cada integrante
│   └── Evidencias Grupales/       Presentación, 1.4, 1.5, planilla de evaluación y acta
├── Fase 2/
│   ├── Evidencias Individuales/   Apellido_Nombre_2.1 (diario de reflexión) y 2.2
│   ├── Evidencias Grupales/       2.4 y 2.6 (guías completadas) y documentos complementarios
│   └── Evidencias Proyecto/
│       ├── Presentación Proyecto.pptx
│       ├── Evidencias de documentación/   Gestión, Scrum, requisitos, arquitectura, pruebas, EDT, presupuesto y retroalimentación
│       └── Evidencias de sistema/
│           ├── Aplicación/        Ubicación del código, pruebas y video
│           └── Base de datos/     Esquema MySQL exportado
└── Plantillas sin completar/      Plantillas de la asignatura que aún no se han llenado
```
